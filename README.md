# hxyfront-62007 植物标本馆入库

源提示词编号：9

开发一个植物标本馆压制标本入库前端项目，工作人员可以录入采集号、物种名称、采集地点、海拔、生境描述、采集人、压制状态、鉴定状态和馆藏位置。页面需要有入库队列、鉴定状态筛选、采集地点信息卡、馆藏柜位记录和单份标本详情页。

## 技术栈

React + Vite + TypeScript

## 本地运行

```bash
npm install
npm run dev
```

开发端口：62007

## 业务规则

- **复份鉴定联动**：同一采集号的多份复份共享鉴定结论。任一复份点「接受鉴定」，同号全部置为已鉴定；任一复份「存疑退回」，同号全部回到待鉴定，且历史结论保留不删除。
- **柜位互斥与分散**：同号复份整组一次分配，必须分散到不同柜位；柜位已被其他标本占用、同号合柜或任一复份压制未完成时，整次分配拒绝，原队列与柜位记录不变（事务）。
- **海拔区间**：采集地点卡登记允许入库的海拔区间，入队时越界标本整批拒绝。
- **联动与持久化**：筛选同时作用于入库队列与柜位记录，点击任意标本进入单份详情页；全部状态只写入浏览器 localStorage，刷新后保留，可用侧栏「重置为演示数据」清空。
